# VJ_yattaro 安定版

**Source build: `2026-10-22-stable-v2`**

ベース: `2026-10-20-shazam-tieup-priority-v1`

Rekordbox / Shazamの曲情報からYouTube動画を検索・再生するWindowsアプリです。
このZIPは**ビルド用ソース一式**です。ビルド済みEXEは含みません。
個人設定・APIキー・認識履歴・実行ログ・仮想環境・生成物は除外しています。

## 今回の変更

**タイアップ補完後のYouTube検索で0件になった場合、次の順に再検索します。**

1. 補完後検索テンプレート（既定：`%tracktitle% %comment%`）
2. 通常Shazam検索テンプレート（既定：`%tracktitle% %artist%`）
3. 通常Shazam検索からアーティスト名を省略（既定：`%tracktitle%`）

例：`Dolphin☆jet / 彩音 / ケンコー全裸系水泳部 ウミショー オープニング` は、
`Dolphin jet ケンコー全裸系水泳部 ウミショー オープニング` →
`Dolphin jet 彩音` → `Dolphin jet` の順になります（記号の検索用正規化は従来のまま）。
**有効な動画結果が見つかれば、その時点で終了**します。
検索結果0件（フィルター後0件も含む）の場合だけ次へ進み、APIエラーでは語を削りません。
重複した検索語は省略し、最大3種類の検索に限定します。
再検索もタイアップ補完後の新しい検索処理として扱い、旧通常検索の動画をそのまま自動再生することはありません。

Shazam履歴の列は「曲名 / アーティスト名 / コメント」のままです。
**仮状態の表示をコメント欄へ移しました。**

| 状態 | コメント欄の表示例 |
|---|---|
| 1回目の認識、コメントなし | `(仮)` |
| 仮状態、タイアップ取得済み | `(仮) 薫る花は凛と咲く エンディング` |
| 2回一致後、曲情報の確定待ち | `(確定・情報補完中)` + コメント |
| 確定した履歴 | コメント本文のみ（なければ空欄） |

状態ラベルは**表示専用**です。`%comment%`、曲名、アーティスト名、保存コメントに混入しません。
2回一致判定・候補の期限・自動再生の安全条件は変更していません。
仮状態を長く見せるための待ち時間も追加していません。

## ビルドと起動

既存スクリプトの前提: Windows / Python 3.12（64-bit）/ Microsoft Edge WebView2 Runtime。
初回ビルドには依存関係のダウンロードが必要です。
.NET SDKがない場合、既存のビルド処理がユーザー領域へ.NET 8 SDKを導入します。

ZIPを新しいフォルダーに展開し、`VJ_yattaro_stable`内で実行します。

```powershell
.\build.cmd
.\dist\VJ_yattaro\VJ_yattaro.exe
```

依存関係が導入済みなら ` .\build.cmd -SkipInstall ` で再ビルドできます。
配布するのは **`dist\VJ_yattaro`フォルダー全体**です。EXE単体では動作しません。

## 既存設定の引き継ぎ

旧版とプレーヤーを閉じ、旧版EXEと同じフォルダーにある `config.json` と `shazam_history.json` をバックアップしてください。
別フォルダーでビルドした場合は、新版の初回起動前にこの2ファイルを `dist\VJ_yattaro` にコピーします。
同じソースフォルダーで再ビルドする場合、既存のビルド処理は配布先の設定・履歴を維持します。
旧フォルダーへの上書き展開だけでは、廃止した資料や生成物は残ります。新規展開を推奨します。

## 設定の要点

| 項目 | 新規設定の既定値 |
|---|---|
| Shazamレーン数 | 6（4～16） |
| Shazam通常検索 | `%tracktitle% %artist%` |
| タイアップ補完後検索 | `%tracktitle% %comment%` |
| Rekordbox検索 | `%tracktitle% %comment%` |
| 自動再生 / タイアップ補完 | OFF |

保存済み設定は維持します。歌ネットの許諾確認も従来どおりで、この版で自動的に有効化しません。
